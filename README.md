# LanIPScanner for Windows
一个普通的多线程局域网IP扫描工具
## 软件由来
作者闲着没事干用AI做出来的东西<br>
（作者PS：其实网上有很多比我这个做的更好的工具了，我做这个纯属白搭）
## 支持系统
Windows 10~11
## 软件功能
- IP占用扫描
- DHCP服务器扫描<br>
